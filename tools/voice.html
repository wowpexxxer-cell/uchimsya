Озвучка всех фраз разом

Страница сама пройдёт по списку фраз, озвучит каждую в ElevenLabs и соберёт все mp3 в один архив с правильными именами. Ключ остаётся в этом браузере и уходит только в ElevenLabs.

1 Ключ ElevenLabs

На сайте ElevenLabs откройте Settings → API Keys, нажмите «Create API Key». В доступах включите Text to Speech и Voices: Read. Скопируйте ключ и вставьте сюда. Никому его не присылайте.

2 Голос

Выберите голос и нажмите «Пример»: прозвучит «Привет! Давай учиться!». На бесплатном тарифе работают только голоса из первой группы списка. Для детей хорошо подходят спокойные женские голоса, например Sarah, Alice или Matilda.
