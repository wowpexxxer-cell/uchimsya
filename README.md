# Учимся играя

Приложение для планшета, чтобы учить ребёнка буквам, а потом счёту. Работает в браузере и ставится на главный экран как обычное приложение (PWA), после первого открытия работает без интернета.

## Что уже есть

**Азбука** (33 буквы русского алфавита)
- Карточка буквы: большая буква, картинка и слово, буква звучит вслух.
- «Написать»: ребёнок обводит букву пальцем по пунктирной дорожке, большую или маленькую, и получает от 1 до 3 звёздочек.
- Игра «Какая буква потерялась?»: 10 слов-картинок, нужно выбрать первую букву.

**Счёт**: пока заготовка, цифры 1–10 с озвучкой. Следующий шаг: игры со счётом.

Звёздочки и прогресс хранятся на самом планшете.

## Как поставить на планшет

1. Включите GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
2. Откройте адрес `https://<логин>.github.io/<репозиторий>/` на планшете.
3. iPad (Safari): «Поделиться» → «На экран „Домой“». Android (Chrome): меню ⋮ → «Установить приложение».

## Устройство

```
index.html            оболочка приложения
styles.css            оформление
js/alphabet.js        буквы, слова и картинки
js/math.js            данные раздела «Счёт»
js/app.js             экраны, письмо, игра, озвучка
sw.js                 офлайн-кэш (при изменениях поднимайте VERSION)
tools/build-artifact.py  собирает всё в один HTML для предпросмотра
```

Озвучка использует встроенный голос устройства (Web Speech API). На iPad русский голос есть по умолчанию; если звука нет, проверьте, что выключен беззвучный режим.
