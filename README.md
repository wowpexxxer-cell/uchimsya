# Учимся играя

Приложение для планшета, чтобы учить ребёнка буквам, а потом счёту. Работает в браузере и ставится на главный экран как обычное приложение (PWA), после первого открытия работает без интернета.

## Что уже есть

- **Вход по имени.** Каждый ребёнок выбирает себя на первом экране, у каждого свой прогресс и звёздочки. Хранится на самом планшете.
- **Карта уроков** с совёнком-помощником. Уроки открываются по очереди:
  1. **Буквы** (11 уроков по 3 буквы в порядке букваря): знакомство с буквой, обвести пальчиком, «найди букву по звуку», «с какой буквы начинается слово».
  2. **Читаем по слогам** (8 уроков): буква «бежит» к гласной и получается слог, «найди слог», «собери слово из слогов».
  3. **Счёт 1–10** (4 урока): посчитай картинки, обведи цифру, «сколько здесь картинок?».
  Слоги и счёт открываются, когда пройдены все буквы.
- **Свободный режим**: все буквы с письмом и игра «Какая буква потерялась?».
- **Для родителей** (кнопка с именем ребёнка): прогресс, смена ученика, «открыть все уроки», сброс.

## Как поставить на планшет

1. Включите GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
2. Откройте адрес `https://<логин>.github.io/<репозиторий>/` на планшете.
3. iPad (Safari): «Поделиться» → «На экран „Домой“». Android (Chrome): меню ⋮ → «Установить приложение».

## Устройство

```
index.html            оболочка приложения
styles.css            оформление
js/data.js            буквы, уроки, слоги, числа, фразы
js/voice.js           озвучка: записи из audio/ или встроенный голос
js/app.js             экраны, уроки, письмо, игры, профили
audio/                записанные фразы (*.mp3) и их список index.json
audio/LIST.md         что озвучить в ElevenLabs и как назвать файлы
sw.js                 офлайн-кэш (при изменениях поднимайте VERSION)
tools/audio-list.js   пересобирает audio/LIST.md из js/data.js
tools/build-artifact.py  собирает всё в один HTML для предпросмотра
```

## Озвучка

Если для фразы есть файл `audio/<имя>.mp3` и он перечислен в `audio/index.json`, играет запись. Иначе говорит встроенный голос устройства. Список того, что нужно записать, лежит в `audio/LIST.md`. Если звука нет совсем, проверьте, что на планшете выключен беззвучный режим.
